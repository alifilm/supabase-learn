- Examples:
  - 例子1：考研学习卡片
    - 功能：用户可以添加考研知识点卡片，每张卡片包含知识点标题、详细内容、复习日期等信息，支持编辑和删除操作。
    - 界面：卡片采用iOS风格的圆角矩形设计，背景颜色为浅灰色，文字清晰易读，卡片之间有适当的间距，整体布局简洁美观。
    - 操作流程：用户点击“添加卡片”按钮，进入编辑界面，输入知识点标题和内容，设置复习日期，点击“保存”按钮后，新卡片出现在卡片列表中。
  - 例子2：英语学习卡片
    - 功能：用户可以创建英语单词或短语卡片，每张卡片包含单词、音标、释义、例句等内容，支持发音功能，方便用户学习和复习。
    - 界面：卡片设计与考研卡片风格一致，但颜色稍有区别，以区分不同学习内容。卡片上的单词和释义字体较大，音标和例句字体较小，发音按钮采用iOS风格的圆形图标。
    - 操作流程：用户点击“添加英语卡片”按钮，输入单词、音标、释义和例句，点击“保存”按钮后，新卡片出现在英语学习卡片列表中，点击卡片上的发音按钮可以听到单词发音。
  - 例子3：考编学习卡片
    - 功能：用户可以记录考编的政策信息、备考计划、重要知识点等内容，支持分类显示和搜索功能，方便用户快速查找所需信息。
    - 界面：考编卡片的布局和设计与其他卡片保持一致，但内容更加丰富，包括政策信息卡片、备考计划卡片和知识点卡片等，每种卡片都有不同的颜色标识。
    - 操作流程：用户点击“添加考编卡片”按钮，选择卡片类型，输入相应内容，点击“保存”按钮后，新卡片出现在考编学习卡片列表中，用户可以通过分类或搜索功能快速找到特定类型的卡片。
